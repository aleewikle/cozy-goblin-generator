# The Cozy Goblin Generator

Discover your woodland goblin identity!

The Cozy Goblin Generator is a whimsical web application that creates randomized goblin names, woodland occupations, magical possessions, and personality descriptions.

## Features

- Randomly generated goblin identities
- Funny woodland occupations
- Magical possessions
- Cozy, storybook-inspired design
- Unlimited goblin generations

## Built With

HTML, CSS, and JavaScript, with assistance from AI-powered coding tools.

Under development.
